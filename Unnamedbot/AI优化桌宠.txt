总纲
	运行在Windows 10+（含Windows 11）
	使用C++17（兼容ISO C++17标准），工具集v145（Visual Studio 2026）
	使用Visual Studio 2026编译，项目配置为x64 Release/Debug
	严格区分头文件（.h）与实现文件（.cpp），根据模块职责拆分为多个独立文件（如Core、Renderer、AI、Database、Live2D、Tray等）
	渲染引擎使用DirectX 11（Feature Level 11.0及以上），支持硬件加速
	第三方依赖管理：使用vcpkg或NuGet引入SQLite3、nlohmann/json、cpr（HTTP客户端）、Live2D Cubism SDK for Native（5.x+）等，所有依赖版本锁定并记录在文档中

目标
	实现一个运行在Windows桌面的智能桌宠软件，具备以下核心能力：
	- 基于Live2D的生动角色呈现，支持点击穿透与精准交互
	- 集成大语言模型（LLM）API，实现自然对话与工具调用（MCP协议）
	- 主动感知环境（前台进程、天气、IP变动、屏幕截图）并触发智能对话
	- 完善的本地数据持久化（SQLite3），支持多会话、历史记录、配置管理
	- 高可配置性（采样参数、隐私策略、定时任务、模型切换）
	- 低资源占用，具备后台降帧、断网重试、日志轮转等生产级特性

运行要求
	充分使用AI的API接口功能（支持OpenAI兼容接口、Azure、Ollama等）
	使用sqlite3数据库存储对话信息（按会话ID组织）、配置信息（键值对）、模型状态（坐标、缩放、透明度、当前模型ID）、附件索引、定时任务等
	支持配置AI请求的采样参数：温度（Temperature，范围0.0~2.0）、Top-P（0.0~1.0）、频率惩罚（Frequency Penalty）、存在惩罚（Presence Penalty），并提供合理的默认值
	支持配置AI请求为流式（Stream）或非流式，默认开启流式以提升交互体验；流式超时时间可配置（默认30秒）

运行逻辑
	初次打开应用时，要求配置API接口基址（Base URL）、API KEY、默认模型名称（如 gpt-4o）、以及可选的组织ID等常规信息；若检测到已有配置则跳过，允许用户通过托盘菜单重新配置
	然后，可以选择关闭GUI窗口，但保留进程在Windows小托盘（系统托盘）中，图标支持右键菜单（显示/隐藏桌宠、打开消息框、打开配置、退出程序）
	桌宠使用Live2D的Cubism SDK for Native开发包提供对Live2D模型的支持（.moc3、.json、纹理图集等）
	配置好Live2D模型后，在桌面绘制模型窗口，窗口无边框、无标题栏、无任务栏按钮（WS_EX_TOOLWINDOW）
	Live2D模型的“碰撞框”仅限于模型的非透明部分，不遮挡其余部分的其他软件窗口
		- 具体技术实现：窗口设置扩展样式 WS_EX_LAYERED 与 WS_EX_TRANSPARENT，通过 WM_NCHITTEST 返回 HTTRANSPARENT 实现点击穿透
		- 精确点击判定：结合 Live2D 的 IsHit() 进行像素级射线检测，仅非透明像素响应交互；同时支持鼠标悬停时显示手型光标
		- 左键交互区分：按下时间 < 200ms 判定为“单击”（开/关消息框），≥ 200ms 判定为“长按拖拽”（移动模型位置）；拖拽时窗口跟随，释放后保存坐标到配置表
		- 支持配置“置顶模式”，默认开启，确保桌宠始终显示在桌面最上层（WS_EX_TOPMOST）；当检测到全屏应用（如游戏、视频播放器）时可自动临时隐藏，避免遮挡
		- 支持多显示器环境：窗口可跨显示器拖动，坐标存储为绝对屏幕坐标；DPI感知采用 Per-Monitor V2，确保在高DPI下缩放正确
		配置中，时间为负的即为不启动此功能（例如定时刷新间隔设为 -1 表示禁用）
		根据配置，每隔一定时间刷新进程表，获取前台（即任务管理器下的“应用”栏）进程列表（含窗口标题、可执行路径），并连同时间一同发送给AI，主动触发特殊对话（如“你注意到我在用什么软件吗？”）
		根据配置，每隔一段时间获取IP对应位置的天气信息（使用高德的天气查询，参阅https://lbs.amap.com/api/webservice/guide/api/weatherinfo，APIKEY要求用户自行配置），并主动触发特殊对话（如“今天外面下雨，记得带伞”）
		根据配置，每次刚开始时获取IP地址（通过外部服务如 ip-api.com），并记录到数据库；如若两次IP位置（城市级别）相差太远（经纬度距离 > 阈值，默认100km）则主动触发特殊对话（如“你换城市了？”）
		根据配置，每隔一段时间获取桌面截图（使用DXGI屏幕捕获或GDI），发送给AI图片模型（如gpt-4-vision）或者常规模型（转为Base64描述），主动触发特殊对话（如“你桌面上好多文件，需要整理吗？”）
		*以上所有主动触发行为，均受全局冷却（Cooldown）机制限制，最短触发间隔可配置（默认8分钟），防止高频调用导致AI请求泛滥；冷却期内的触发事件将被丢弃并记录日志*
		
		在桌面的模型中，左键单击打开（关闭）消息框（非模态窗口，置顶于模型之上但可穿透？实际消息框为独立窗口，位于模型旁边或下方，位置可记忆）
		在桌面的模型中，左键长按拖动模型（整个窗口移动）
		在桌面的模型中，右键单击，可以打开配置菜单或者使用部分“根据配置”的内容（内容表上限可以配置，默认显示最近5条主动触发建议）
			- 右键配置菜单采用独立非模态窗口（Popup窗口），避免遮挡模型交互与消息框；菜单项动态生成，支持自定义快捷操作（如“立即截图”、“查天气”）
			- 托盘图标同样支持右键菜单：显示/隐藏桌宠、打开消息框、打开配置、切换模型、退出程序
		
		在消息框中，可以选择附带文件（任意类型，除非模型不支持，如图片模型只接受图片格式）
			- 单次附带文件大小限制默认 ≤ 20MB（可配置），总附件磁盘占用量自动限制（默认500MB），超30天未引用的附件自动清理（可配置保留天数）
			- 支持拖拽文件到消息框区域自动添加附件
		
		当同时按下“a”和“l”键时（不区分大小写，且无其他修饰键），保存所有状态并安全关闭进程（优雅退出，清理临时资源）
		
		*模型状态持久化：用户拖拽后的屏幕坐标（X,Y）、缩放比例（0.5~2.0）、透明度（0.2~1.0）、当前使用的模型ID，均定时（每5秒）存入SQLite配置表，程序重启后自动恢复*
		*支持多套Live2D模型热切换（无需重启程序），用户可导入本地模型文件（.moc3、.json、纹理等），切换时保留当前对话上下文；模型库存储在 ./models/ 目录下*
		*增加断网/离线模式：当所有AI接口不可达（HTTP 4xx/5xx或超时）时，桌宠自动显示“休眠/离线”特定动画（如闭眼、趴桌），本地缓存用户发出的消息（按会话存储），待网络恢复后按序重试发送（最多重试3次）*
		*扩展性支持：提供“自定义定时任务”插件接口，用户可基于Cron表达式配置个人提醒（如每周五 16:00 提醒开会），任务数据存储在SQLite中，任务触发时调用AI生成提醒内容或执行预设动作*
		*开发者调试模式：支持热键 Ctrl+Shift+D 唤出调试悬浮窗，实时显示DX11渲染帧率（FPS）、显存占用（MB）、AI请求耗时（ms）、SQLite查询耗时及日志输出（级别可过滤）*
		*安全与权限管理：API KEY以加密形式（Windows DPAPI）存储于配置表中，避免明文泄露；所有网络请求使用HTTPS；本地附件扫描防止恶意文件类型（可配置白名单）*
		*更新与升级：支持自动检查更新（GitHub Release或私有服务器），下载新版本后提示用户安装；更新过程中保留用户配置和数据库*

日志系统
	记录运行日志（级别：info / warn / error / debug），日志格式为 [时间] [级别] [模块] 消息
	日志文件按天分割，存放在 ./logs/ 目录，命名如 app_2026-09-05.log
	保留最近30天日志，过期日志自动删除（可配置保留天数）
	日志输出同时支持文件和控制台（Debug模式时），并可选择发送到调试悬浮窗

渲染与性能优化
	模型显示时（前台可见）渲染帧率默认 30fps；当窗口最小化、隐藏、被完全遮挡或失去焦点时，自动锁定帧率至 10fps 并降低DX11 Present调用频率（使用Sleep或WaitableTimer），节约GPU资源
	纹理资源按需加载，模型切换时释放旧资源；显存占用监控，超出阈值（默认1GB）时自动清理未使用的缓存
	支持垂直同步（VSync）开关，默认关闭以减少输入延迟

对话运行逻辑（核心）
	基于最大上下文长度（用户可配置Token数，默认4096，或轮次数，默认30轮），在每次请求前裁剪历史消息，优先保留最近的系统角色及关键轮次（用户/助手交替），确保不超阈值；裁剪策略为从最早的非系统消息开始移除
	合并用户自定义前置词（Pre-prompt，插在系统提示之后）、后置词（Post-prompt，插在用户消息之后）及系统角色映射（System Prompt，如“你是一个活泼的桌宠”），构建完整的请求消息体
	携带当前配置的采样参数（温度、Top-P、频率惩罚等）与已绑定的MCP工具列表（Tools），工具定义符合OpenAI Function Calling规范（JSON Schema）
		MCP工具列表具体包含：
		- get_current_time()：获取当前系统时间（含时区）
		- get_frontend_processes()：获取当前前台应用进程列表（含窗口标题、可执行名）
		- get_weather(city)：查询指定城市天气（依赖高德API）
		- get_screen_capture()：获取桌面截图（受隐私策略过滤，返回Base64或URL）
		- open_url(url) / send_notification(text)：需用户二次确认（弹窗）的主动执行工具，默认禁用，需用户显式授权
		- 预留扩展接口，用户可添加自定义工具（如查询日历、控制智能家居）
	通过MCP协议提交 CreateMessage 请求（依据配置选择流式或非流式），请求超时时间默认60秒
	若AI响应触发了工具调用（Function Call / Tool Use），则自动循环执行对应工具（MCP服务端），将工具返回结果再次提交给AI，直至得到最终的自然语言响应（最多循环5次，防止死循环）；每次循环都记录中间步骤并显示在消息框（折叠）
	将生成结果按角色映射（user / assistant / system / tool）规范化后，存入sqlite3数据库（按会话ID组织），并实时渲染到消息框UI中（流式模式下逐字打印，支持Markdown渲染）
	若API调用失败或超时，自动重试最多3次（指数退避：1s, 2s, 4s），并明确提示用户错误原因（如“API密钥无效”、“网络连接失败”）
	支持多模态输入：若用户附带图片，自动转换为Data URL或上传至临时存储，并调整请求为多模态格式

消息对话管理（基于上述逻辑的存储与展示）
	当生成对话后，执行以下操作：
		- 将生成的对话内容（包括用户消息、AI回复、时间戳、附带文件信息、消耗Token数（prompt_tokens, completion_tokens）等）存入sqlite3数据库，并按会话ID组织
		- 根据配置的最大上下文长度，自动裁剪历史记录，只保留最近N条对话（N由用户配置，默认50条）
		- 若用户开启了“主动触发特殊对话”，则根据当前上下文和触发事件（进程、天气、IP变动、截图）生成一段额外的AI主动发言，并同样存储和显示（标记为 system 或 assistant 角色，且注明触发来源）
		- 在消息框中显示最新的对话内容，并自动滚动到底部；若消息框处于关闭状态，则托盘图标闪烁提示有新消息
		- 如果对话中附带文件，需将文件保存至本地指定目录（如 ./attachments/ 并按会话ID/日期分目录），并在数据库中记录文件路径、类型（MIME）、大小、原始文件名
		- 对于图片模型生成的回复（如图片生成），需在消息框中显示缩略图（保持宽高比），并支持点击查看大图（使用系统默认图片查看器或内嵌预览）
		- 所有对话记录支持按时间、关键词搜索（SQL LIKE 或 FTS5全文索引），并提供导出功能（导出为JSON或TXT，包含元数据）
		- 当AI回复包含可执行指令（如“打开浏览器”、“发送邮件”等），需经用户二次确认（弹窗）后才可执行，并记录授权日志以提高安全性
		- 用户可随时清空当前会话（删除所有消息，保留会话元数据）或删除单条对话记录（物理删除或软删除）
		- 支持多会话管理（新建、切换、删除会话），每个会话独立存储上下文、模型配置、采样参数；会话列表展示在消息框侧边栏
		- 用户可在配置菜单中设置默认模型（文本/图片/多模态），并切换不同API提供商（如OpenAI、Azure、本地Ollama等），切换时自动更新请求端点

补充功能
	支持开机自启动选项（写入Windows注册表或计划任务）
	所有配置（API信息、功能开关、定时参数、模型偏好、采样参数、隐私策略、快捷键绑定等）保存在sqlite3的配置表中，并支持导入/导出配置文件（JSON格式），便于备份和迁移
	支持主题切换（亮色/暗色/跟随系统），消息框和配置窗口UI采用现代化设计（可使用ImGui或WPF混合托管？但原定C++，建议使用DirectUI或Qt？为保持轻量，使用Win32原生控件或DUI库）
	提供全局热键（可自定义）：如 Ctrl+Alt+M 切换消息框显示，Ctrl+Alt+T 切换置顶模式
	错误处理与崩溃恢复：程序异常退出时，自动记录崩溃日志（minidump），下次启动时提示是否恢复未保存的对话
	国际化与本地化：支持中文（简体）和英文界面，可根据系统语言自动切换，语言资源文件为JSON格式
	性能监控与统计：记录每日对话次数、Token消耗量、主动触发次数，并可在配置窗口查看统计图表（简易）
	支持代理配置（HTTP/SOCKS5），满足企业网络环境
