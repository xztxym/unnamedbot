UnnamedBot 桌宠中控
====================

安装位置：%LOCALAPPDATA%\Programs\UnnamedBot（按用户安装，无需管理员权限）

Unnamedbot.exe 主程序；cpr/libcurl/z/sqlite3 为 HTTP 与数据库运行时；
Live2DCubismCore.dll Live2D 运行库；msvcp140/vcruntime140* VC++ 运行库（随包）；
FrameworkShaders 渲染着色器；models\Haru、models\wuwuwu 两个 Live2D 模型；
redists\MicrosoftEdgeWebView2Setup.exe WebView2 引导程序（系统未自带时运行）。

卸载：设置 → 应用 → 已安装的应用 → UnnamedBot
